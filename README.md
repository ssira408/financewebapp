# สมุดเงิน — เว็บแอปพร้อมฐานข้อมูล

## สิ่งที่เพิ่มจากไฟล์ HTML เดิม
- สมัครสมาชิก / เข้าสู่ระบบ / ออกจากระบบ
- แยกข้อมูลตามบัญชีผู้ใช้
- บันทึกและโหลดข้อมูลจาก MySQL ผ่าน PHP API
- รหัสผ่านเก็บด้วย `password_hash()` ไม่เก็บรหัสผ่านดิบ
- ยังคงเก็บสำรองใน localStorage ของเบราว์เซอร์
- หน้าเดิมสำหรับรายรับรายจ่าย บิล เงินเก็บ แผนออม หนี้ เป้าหมาย และรายการอยากได้ยังอยู่

## สิ่งที่ต้องใช้
- PHP 8.1+ พร้อมส่วนขยาย PDO MySQL
- MySQL 8+ หรือ MariaDB
- Apache/Nginx หรือ XAMPP

## ติดตั้งบน XAMPP (Windows)
1. แตก ZIP นี้ไว้ที่ `C:\xampp\htdocs\finance-webapp`
2. เปิด XAMPP แล้ว Start **Apache** และ **MySQL**
3. เข้า `http://localhost/phpmyadmin`
4. Import ไฟล์ `database.sql`
5. เปิด `api/config.php` และตรวจค่าเชื่อมต่อฐานข้อมูลให้ตรงกับเครื่อง หากใช้ XAMPP ค่าเริ่มต้นมักเป็น `root` และรหัสผ่านว่าง
6. เข้า `http://localhost/finance-webapp/`
7. สมัครสมาชิก แล้วเริ่มใช้งาน

## ตั้งค่าฐานข้อมูลบนโฮสต์
ตั้ง Environment Variables: `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`. อย่าใช้บัญชี root ใน production; สร้างผู้ใช้ฐานข้อมูลที่มีสิทธิ์เฉพาะฐานข้อมูลนี้

## หมายเหตุสำคัญ
- ต้องเปิดผ่าน PHP server เช่น `http://localhost/finance-webapp/` ไม่ใช่ดับเบิลคลิกเปิดไฟล์ HTML
- ข้อมูลที่มีอยู่ใน localStorage ของไฟล์เดิมจะไม่ถูกอัปโหลดอัตโนมัติก่อนสมัคร/เข้าสู่ระบบ หากต้องการย้ายข้อมูล ให้ส่งออกไฟล์ JSON จากแอปเดิม และใช้หน้าตั้งค่า/นำเข้าข้อมูลหลังเข้าระบบ
- แนะนำให้ใช้ HTTPS เมื่อนำขึ้นอินเทอร์เน็ต และสำรองฐานข้อมูลเป็นประจำ
- แอปเก็บข้อมูลสถานะเป็น JSON ต่อบัญชี เพื่อรักษาฟีเจอร์เดิมที่มีโครงสร้างซ้อนกัน หากต้องการรายงาน SQL แยกตารางแบบละเอียด สามารถต่อยอดจากโครงสร้างนี้ได้
